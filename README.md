# NHANES 1999–2004 항핵항체(ANA) 양성 예측 모델

인구학·생활습관·임상 변수로 **항핵항체(ANA) 양성**을 예측하고, 어떤 요인이 ANA 양성과 연관되는지 분석한 프로젝트입니다.

ANA는 루푸스, 쇼그렌증후군 등 전신 자가면역질환에서 가장 먼저 나타나는 자가항체로, 진단 수년 전부터 양성이 될 수 있습니다. 이 프로젝트는 일반 인구에서 **자가면역 전단계 신호를 가진 사람을 찾을 수 있는지**를 묻는 출발점입니다.

## 연구 질문

1. 미국 성인에서 ANA 양성 유병률은 얼마이며, 인구집단별로 어떻게 다른가?
2. 어떤 요인이 ANA 양성과 독립적으로 연관되는가?
3. 일상적으로 수집되는 변수만으로 ANA 양성을 얼마나 예측할 수 있는가?

## 데이터

| 항목 | 내용 |
|---|---|
| 출처 | 미국 국민건강영양조사 [NHANES](https://wwwn.cdc.gov/nchs/nhanes/) 1999–2004 (공개 자료) |
| ANA 측정 | HEp-2 세포 간접면역형광법, 핵 염색 강도 0~4 |
| 결과 변수 | 핵 염색 강도 ≥3 → ANA 양성 (선행연구 정의를 따름) |
| 대상 | ANA 하위표본 4,532명 중 20세 이상 비임신 성인 **3,242명** (양성 394명, 12.2%) |
| 가중치 | ANA 하위표본 전용 6년 가중치 `WTANA6YR` |

**사용 파일 (16개)**

| 내용 | 1999–2000 | 2001–2002 | 2003–2004 |
|---|---|---|---|
| ANA | `SSANA_A` (3주기 통합) | | |
| 인구학 | `DEMO` | `DEMO_B` | `DEMO_C` |
| 신체계측 | `BMX` | `BMX_B` | `BMX_C` |
| 흡연 | `SMQ` | `SMQ_B` | `SMQ_C` |
| 병력 | `MCQ` | `MCQ_B` | `MCQ_C` |
| CRP | `LAB11` | `L11_B` | `L11_C` |

**예측 변수**: 연령, 성별, 인종/민족, 소득 대비 빈곤선 비율, 교육수준, BMI, 흡연 상태, log(CRP), 의사진단 관절염, 자가보고 류마티스관절염, 갑상선 질환

ANA 염색 패턴과 특이항체 변수는 결과에서 파생된 값이므로 데이터 누수를 막기 위해 예측 변수에서 제외했습니다.

## 분석 방법

1. **기술통계**: 가중 ANA 유병률 (성별, 연령군, 인종, 흡연별)
2. **연관성 분석**: 가중 로지스틱 회귀로 보정 오즈비(OR) 추정
3. **예측 모델**: 로지스틱 회귀, 랜덤포레스트, 히스토그램 그래디언트 부스팅
   - 학습 80% / 테스트 20% 층화 분할, 학습셋에서 5-fold 교차검증
   - 결측 대치·표준화·원-핫 인코딩을 파이프라인 안에서 수행해 정보 누수 방지
   - 클래스 불균형 대응: `class_weight="balanced"`
4. **평가**: ROC-AUC (부트스트랩 95% CI), PR-AUC, Brier 점수, 보정 곡선, 상위 위험군 선별 성능, 하위군 성능
5. **해석**: 순열 중요도 (테스트셋 기준)

## 주요 결과

### 1. 유병률

- 전체 가중 ANA 양성 유병률: **12.2%**
- 여성 16.1% vs 남성 8.1%로 **여성이 약 2배**
- 연령군 간 차이는 작았습니다 (20–39세 12.2%, 40–59세 11.5%, 60세 이상 13.5%).

### 2. 연관 요인 (보정 OR)

| 요인 | OR (95% CI) | p |
|---|---|---|
| 여성 | **2.07** (1.64–2.60) | <0.001 |
| 갑상선 질환 | **1.82** (1.15–2.87) | 0.010 |
| BMI (1 단위당) | **0.97** (0.95–1.00) | 0.016 |
| 비흡연 (vs 현재흡연) | 1.34 (1.01–1.79) | 0.046 |
| 연령 (10세당) | 0.98 (0.91–1.06) | 0.563 |
| log(CRP) | 1.00 (0.90–1.10) | 0.950 |

- 여성, 갑상선 질환, 낮은 BMI가 ANA 양성과 연관되었습니다. 여성과 정상 체중에서 ANA가 많다는 선행연구 결과와 일치합니다.
- CRP로 본 전신 염증은 ANA 양성과 연관이 없었습니다.

### 3. 예측 성능 (테스트셋, n=649)

| 모델 | ROC-AUC (95% CI) | PR-AUC | Brier |
|---|---|---|---|
| **로지스틱 회귀** | **0.603** (0.541–0.665) | 0.148 | 0.239 |
| 랜덤포레스트 | 0.595 (0.533–0.658) | 0.148 | 0.190 |
| 그래디언트 부스팅 | 0.550 (0.479–0.619) | 0.137 | 0.201 |

PR-AUC 기준선(유병률)은 0.122입니다.

- 세 모델 모두 예측력이 **낮은 수준(AUC ≈ 0.6)**이었고, 복잡한 모델이 단순한 로지스틱 회귀보다 낫지 않았습니다. 변수 간 비선형 관계보다 **변수 자체의 정보량이 부족한 것**이 한계로 보입니다.
- 위험 점수 상위 30%를 선별하면 양성자의 40.5%를 포착했고, 양성예측도는 유병률의 1.35배였습니다.

### 4. 변수 중요도

순열 중요도 기준으로 **성별**(AUC 감소 0.089)이 압도적이었고, 다음이 **BMI**(0.027)였습니다. 나머지 변수의 기여는 0에 가까웠습니다.

## 결론

- 성별, 갑상선 질환, BMI는 ANA 양성과 유의하게 연관되었지만, **일상적인 인구학·생활습관 변수만으로는 ANA 양성을 충분히 예측하기 어려웠습니다.**
- 연관성이 있다는 것과 예측력이 있다는 것은 다른 문제임을 보여주는 결과입니다.
- 실제로 쓸 만한 자가면역 고위험군 예측 모델을 만들려면 **유전 정보(PRS), 면역 관련 혈액 지표, 종단 추적 자료**처럼 더 직접적인 정보가 필요합니다. 이는 다중오믹스·종단 데이터 통합 모델이 필요하다는 근거가 됩니다.

## 한계

- **횡단면 자료**: 현재 ANA 상태를 분류할 뿐, 미래 발생을 예측하거나 인과를 말할 수 없습니다.
- **ANA 양성 ≠ 자가면역질환**: 건강한 사람도 상당수가 양성입니다.
- **갑상선 질환 변수 결측 64.7%**: 일부 주기에서만 수집된 변수로, 중앙값/최빈값 대치를 했기 때문에 해당 OR은 신중하게 해석해야 합니다.
- **근사적 가중 분석**: 층(SDMVSTRA)·집락(SDMVPSU)을 반영한 정식 복합표본 분산 추정이 아닙니다. 정확한 추정은 R `survey` 패키지를 권장합니다.
- **자가보고 변수**의 오분류 가능성이 있습니다.
- **외부 검증 없음**: 같은 데이터의 내부 분할로만 평가했습니다.
